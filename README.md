# LEIGH-BIOS — сайт в стиле BIOS по профилю GitHub

Одностраничник, который выглядит и ведёт себя как **BIOS Setup Utility**: POST-экран с тестом памяти,
синие экраны настроек, рамки, CRT-развёртка и навигация с клавиатуры.

Контент собран по публичному профилю
[**leighiaccino856-beep**](https://github.com/leighiaccino856-beep) и его репозиторию
[tg-conv](https://github.com/leighiaccino856-beep/tg-conv) на 25.10.2026.

Стек: **React 19 + Vite + CSS**, без UI-библиотек. Шрифт — растровый **Tiny5** (5-пиксельная сетка, кириллица), а не современный гротеск.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production-сборка в dist/
npm run preview   # посмотреть собранную версию
npm test          # vitest + jsdom
```

## Управление

| Клавиша | Действие                            |
| ------- | ----------------------------------- |
| `↑` `↓` | выбор параметра                     |
| `←` `→` | переключение разделов               |
| `Enter` | изменить / скопировать / открыть    |
| `Esc`   | сбросить сообщение в строке статуса |
| `F10`   | перейти в раздел Exit               |

Мышь тоже работает: вкладки и строки кликабельны.

## Что внутри

| Раздел       | Содержимое                                                                      |
| ------------ | ------------------------------------------------------------------------------- |
| **Main**     | логин, стек, версия прошивки, дата сборки, репозитории, активность               |
| **Advanced** | статистика языков GitHub (Python 99.5% / Dockerfile 0.5%) и детали стека tg-conv |
| **Boot**     | проекты: TG-CONV и этот сайт                                                     |
| **Security** | GitHub, email, дата регистрации профиля, шуточный пароль администратора          |
| **Exit**     | Save / Discard / Load Defaults с перезагрузкой в POST                            |

Соцданные взяты с GitHub API: имя, био и локация в профиле не заполнены, поэтому на сайте
указан только логин — без выдуманных фактов. Email — из локального `git config`.
Описания технологий и цифры (640×640, 60 с, RAM-only, MIT) взяты из README репозитория.

```
public/
  avatar.png              — аватар GitHub (скачан, не хотлинк)
  fonts/tiny5-*.woff2     — пиксельный шрифт Tiny5 (OFL, лежит локально)
  fonts/OFL.txt           — лицензия шрифта

  data.js                 — весь контент: brand, profile, вкладки, строки POST
  App.jsx                 — переключение POST ↔ Setup, CRT-оверлеи
  components/
    BootScreen.jsx        — экран загрузки с тестом памяти и OEM-эмблемой
    SetupScreen.jsx       — вкладки, строки параметров, справка, горячие клавиши
  styles.css              — синий экран, рамки, scanlines, адаптивность
  App.test.jsx            — тесты навигации и действий
```

## Как менять контент

Почти всё живёт в `src/data.js`:

- `brand` — название прошивки, версия и копирайт;
- `profile` — логин, ссылка на GitHub, email, дата регистрации, аватар;
- `tabs` — разделы. У каждой строки есть `label`, `value`, `type` и `help`
  (текст в панели «Item Specific Help»);
- `type` определяет поведение: `info` / `bar` — просто данные, `copy` — копирует значение,
  `link` — открывает ссылку, `denied` — шуточный отказ, `save` / `reboot` / `defaults` — действия раздела Exit;
- `bootLines` — строки POST-экрана.

Чтобы обновить данные после новых коммитов, поменяйте `profile`, строки Main/Advanced и
проекты в `boot`. Аватар лежит в `public/avatar.png` — замените файл, путь менять не нужно.

## Детали

- Все эффекты (scanlines, мерцание, бегущий луч) отключаются при `prefers-reduced-motion`.
- Шрифт Tiny5 (OFL 1.1) хостится локально: `public/fonts`, без запросов к Google Fonts. Все размеры кратны 8 px — пиксельная сетка шрифта остаётся целой.
- Аватар обесцвечен и пикселизирован фильтрами, не тянется с GitHub в рантайме.
- Вёрстка проверена на 1440×900, 1280×720, 390×844 и 844×390 — без горизонтального скролла и обрезки.
